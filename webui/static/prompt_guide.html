📝 视频提示词编写指南

完整参考模式改写输出格式指南

本指南说明如何在完整参考模式下组织和编写改写输出。

所有六个改写部分使用英文编写。仅保留 <d> 内的对话和歌词以及场景中可见文本的原始语言。

描述细节：使 detailed_description 尽可能详细和明确。对于每个镜头，清晰地建立当前构图、主体外观和位置、环境和光照、动作和状态变化、摄像机运动、当前声音，以及参考内容实际出现或生效的点。避免将描述简化为情节摘要或参考关系列表。

镜头、摄像机运动、说话人、对话和普通声音的基本格式与视频提示词编写指南（T2VA / I2VA / FL2VA / L2VA）共享。本指南专注于完整参考模式特有的参考标签、分析部分和格式差异。

1. 整体结构

完整的改写输出按以下顺序包含六个部分：

部分 用途
subject_definitions 定义参考内容及其参考标签
summary 总结任务类型、目标视频和主要参考关系
retention_analysis 描述参考内容如何被保留、转移或重用
detailed_description 按播放顺序描述视觉、动作、镜头、声音和对话
overall_soundscape 总结氛围和物理声音
non_diegetic_music 描述仅观众可听到的背景音乐

2. 参考标签和定义（subject_definitions）

完整参考改写使用四种类型的标签来识别参考内容的来源和角色：

标签 含义
<Subject N> 从参考资产中抽象的可重用或可修改的可见内容
<Picture N> 用作具体目标帧或镜头规划锚点的参考图像
<Video N> 提供编辑源、续接起点或整体视频时间结构的参考视频
<Audio N> 被复制或引用的音频信号
一旦为内容分配了参考标签，它在 subject_definitions、summary、retention_analysis、detailed_description 和音频部分中保持相同的含义。

subject_definitions 定义每个需要单独跟踪的参考内容，如人物、环境、源视频结构或音频轨道。为每项单独成行，解释其标签表示的内容、参考角色和需要遵循的主要特征；当需要明确来源时，命名相应的源资产。如果 <Picture N> 或 <Video N> 仅识别另一个参考项的来源，且后续不会单独分析或使用，则在该项的定义中引用它，不添加单独的行。retention_analysis 记录每个参考项出现的位置，以及它是完全保留、部分保留、转移还是重用。

2.1 <Subject N>

<Subject N> 用于可重用的可见内容，包括：

  • 人物、动物或物体
  • 场景、背景或环境
  • 服装、道具、界面或视觉效果
  • 风格、动作、表情或姿势

它表示将在目标视频中实际使用的内容单元，而不是源文件本身。一个主体可以由多个参考资产定义，一个参考资产可以提供多个主体。

<Subject 1> 是 <Picture 1> 中的年轻女性，有长黑发、蓝色开衫和细银项链。

当同一主体来自多个资产时，合并来源并说明每个资产提供的内容：

<Subject 1> 是外观来自 <Picture 1> 而行走动作来自 <Video 1> 的女性。

2.2 <Picture N>

当参考图像本身用作镜头的首帧、关键帧、末帧、编辑关键帧或构图锚点时，使用独立的 <Picture N>：

<Picture 2> 是 [Shot 1] 的首帧，显示一位女性坐在咖啡馆窗边。

如果图像仅用于定义角色、场景、服装或风格，不要创建独立的图片条目。相反，在相应的 <Subject N> 定义中引用图像来源。

当图像用作故事板或镜头规划参考时，说明它映射到哪些镜头以及提供什么规划信息：

<Picture 3> 是 [Shot 1] 和 [Shot 2] 的故事板参考，定义它们的视角、主体位置和镜头顺序。

2.3 <Video N>

<Video N> 保留用于整体视频关系，如：

  • 编辑原始视频
  • 从原始视频结尾继续
  • 参考原始视频的摄像机运动、剪辑、节奏或时间结构
<Video 1> 是目标视频编辑的源视频。

如果参考视频中的人物、物体、场景、动作或效果被重用为可见内容，它仍然属于 <Subject N>。<Video N> 识别资产或结构来源，不替代主体标签。

2.4 <Audio N>

<Audio N> 表示独立的音频资产或参考视频中启用的同步音频轨道。常见用途包括：

  • 复制全部或部分音频信号
  • 参考背景音乐风格
  • 参考说话人的声音音色和表达方式
  • 使用原始音频中的对话、歌词或音效
  • 参考节拍、节奏或音频连续性

当 <Audio N> 明确对应目标说话人时，在定义中重用该说话人的全局 ID：当说话人映射到已定义主体时，写 <Subject N> (Sx)，否则使用稳定的声音描述后跟 (Sx)。ID 来自目标视频的全局说话人顺序，不在音频定义中独立分配或重新编号。有关说话人编号规则，请参见第 5.4 节：

<Audio 1> 是 <Subject 1> (S1) 的声音音色参考。

当一个音频资产服务于多个角色时，用一个自然句子描述这些角色，而不是创建额外的子部分。

2.5 同一参考视频的视觉和音频轨道

<Video N> 和 <Audio N> 独立编号。每个索引仅表示标签在其自身类别中的顺序，不编码两个类别之间的配对。因此，同一参考视频可能对应 <Video 1> 和 <Audio 2>；不同的索引不妨碍它们来自同一源资产。

普通参考视频不会仅仅因为文件包含声音而创建 <Audio N>。

<Audio N> 定义主要说明音频的角色，不必命名它来自的 <Video N>。仅在需要消除来源歧义时才说明共同来源，例如：

<Video 1> 是目标视频编辑的源视频。
<Audio 2> 是 <Video 1> 的同步音频轨道，在目标视频中重用。

3. summary

本节使用一个简短的英文段落总结目标视频及其参考关系。它以方括号的任务类型前缀开头：

[reference generation] ...
[video editing + reference generation + audio reuse] ...

根据每个参考资产在目标视频中扮演的实际角色选择任务类型：

任务类型 何时使用
keyframe completion 图像用作目标视频的首帧、关键帧、末帧、编辑关键帧或其他具体帧锚点
reference generation 图像、视频或音频资产为角色、场景、风格、动作、摄像机运动、故事板等提供生成指导，不用作具体帧或被编辑或续接的源视频
video editing 直接修改现有源视频；编辑图像或在静态关键帧之间生成不属于此类型
video continuation 新内容从现有源视频继续、扩展、恢复或过渡
audio reuse 相同音频信号被全部或部分重用
audio reference 音频信号不直接复制；仅参考其音乐风格、音色、对话或歌词内容、音效质感、节拍或连续性

当任务满足多个关系时，用 + 组合任务类型，不重复类型。例如，从源视频续接同时使用图像作为末帧写为 [video continuation + keyframe completion]。编辑源视频同时保留其原始音频可写为 [video editing + audio reuse]。

视频或音频的 mere 存在不会自动创建相应的任务类型。如果参考视频仅提供摄像机运动、剪辑或节奏，它通常属于 reference generation。仅当该视频被直接编辑或续接时才使用 video editing 或 video continuation。

编辑源视频时，如果其原始音频仍然可听，也使用 audio reuse。续接源视频而不直接复制音频信号时，如果新音频仅继续原始轨道的可听特征，使用 audio reference。

摘要使用之前定义的 <Subject N>、<Picture N>、<Video N> 和 <Audio N> 标签来描述主要主体、镜头流程和参考资产的角色。不要在本节中引入新的参考标签。

对于视频编辑任务，在任务类型前缀后以以下开头：

目标视频是 <Video 1> 的编辑版本。

4. retention_analysis

本节描述每个参考内容如何在目标视频中被保留、转移、复制或引用。每个参考标签使用一行，保持 subject_definitions 中建立的含义。

4.1 可见内容

<Subject N>、<Picture N> 和 <Video N> 使用以下关系标记。这些标记是输出格式中的固定英文值：

关系标记 含义
fully_preserved 参考内容的定义角色被完全保留
partially_preserved 参考内容仍被使用，但某些定义特征被改变或仅部分保留
attribute_transfer 参考特征被转移到不同的可识别目标主体
weak_reference 仅保留风格、类别、构图或氛围的广泛相似性

主体条目：

<Subject 1> (appears in [Shot 1], [Shot 3]): fully_preserved - ...

图片条目：

<Picture 2> ([Shot 1] first frame): fully_preserved - ...

视频结构条目：

<Video 1> (cut and pacing structure): weak_reference - ...

4.2 音频

<Audio N> 使用以下关系标记：

关系标记 含义
fully_copy 完整源音频作为目标视频的完整最终音频轨道
partially_copy 仅复制部分时间线或选定的音频层，或在复制后添加、删除或替换其他声音
reference 信号不直接复制；仅参考音色、节奏、音乐风格、对话内容或声音质感
weak_reference 仅保留类别或氛围的广泛相似性 
<Audio 1>: fully_copy - <Audio 1> 被 1:1 重用作目标视频的完整最终音频轨道。
<Audio 2>: reference - 目标说话人遵循 <Audio 2> 的声音音色和稳健的表达方式，不复制原始信号。

仅在 subject_definitions 中为该标签定义的参考角色内选择每个关系标记。不要将目标视频中新增的动作、背景或情节事件视为参考保真度的损失。

5. detailed_description

这是完整参考改写的主体。它按目标视频播放顺序逐镜头描述视觉、动作、声音和对话，并在适用的地方插入参考标签。

5.1 基本格式

基本格式遵循视频提示词编写指南（T2VA / I2VA / FL2VA / L2VA）：

  • 主体使用英文编写。保留对话、歌词和可见文本的原始语言。
  • [Shot 1] 标记开场镜头，没有时间戳。后续镜头使用 [Shot N] At MM:SS.mmm, ... 标记剪辑时间。
  • 将摄像机运动写为当前镜头内的自然英文，包括需要表达时的运动类型、幅度和速度。
  • 为声音来源提供稳定的 (S1)、(S2) 及后续 ID。将对话和歌词写为 <d>[语言] ...</d>。
  • 对跨越剪辑的对话、被视频结尾截断的语音和跨镜头的连续音频使用 <scenetrans>、<cutoff> 和相应的连续性描述。

有关涵盖摄像机词汇、群体语音、画外音、跨剪辑对话和可见文本的完整规则和示例，请参见视频提示词编写指南（T2VA / I2VA / FL2VA / L2VA）。

5.2 完整参考模式差异

维度 T2VA 完整参考模式
主字段 integrated_multimodal_description detailed_description
风格开头 写在 [Shot 1] 之后 在 [Shot 1] 之前用一两句话建立
参考信息 不使用完整参考标签 在首次出现和角色适用的地方插入 <Subject N>、<Picture N>、<Video N> 和 <Audio N>
音频关系 描述目标视频自己的声音 在相应镜头或音频阶段引用 <Audio N> 并说明信号是被复制还是引用

开头示例：

目标视频采用电影化、文学性音乐视频风格，光线柔和，色彩略微去饱和。
[Shot 1] 场景在拥挤的城市街道开场...
[Shot 2] 在 00:09.000，镜头切换到极端特写...

对于生成任务，detailed_description 通常为 350-500 个英文单词。对话密集内容优先考虑适应完整的口语时间线，而不是机械地达到字数。视频编辑描述根据源视频的复杂性扩展，不必遵循生成任务范围。单个镜头不自动证明较短的描述是合理的；根据信息负载在多个镜头之间分配细节。

5.3 在镜头中使用参考标签

在重要 <Subject N> 首次清晰出现时，在镜头中实际可见的内容内描述其参考特征、帧中位置和当前动作。在后续镜头中继续使用相同标签，不重新定义标签代表的内容。

对具体帧锚点使用自然措辞：

镜头从 <Picture 1> 开始
镜头的关键帧对应 <Picture 2>
镜头在 <Picture 3> 结束

编辑或续接原始视频时，在其源状态、结构或续接关系适用的地方自然地引用 <Video N>。在音频关系活跃的镜头或语义阶段引用 <Audio N>。

5.4 说话人、音频来源和对话

基本的说话人 ID 和 <d> 格式遵循 T2VA。当参考主体实际说话时，保留视觉参考标签和说话人 ID：

<Subject 2> (S1) 转向女性并说，<d>[English] Last summer, I went to my grandfather's house. He talked about you.</d>

<Subject N> 识别参考主体，而 (Sx) 识别实际说话人。当主体说话时，写 <Subject N> (Sx)。如果同一主体在画外说话，保持相同形式并标记为 off-screen。当说话人不对应已定义主体时，使用稳定的声音描述后跟 (Sx)。

当口头内容仅作为直接重用的 BGM 或完整配乐中的提示，且没有人物、角色、旁白者或其他独立声音来源实际产生它时，使用 <Audio N> 作为可听来源，不发明额外的 (Sx)。如果具体人物、角色、旁白者或其他独立声音来源产生声音，为该来源分配并重用 (Sx)：

当 <Audio 1> 到达短语 <d>[English] I'm lonely lonely lonely lonely lonely I'm lonely</d> 时，<Subject 1> 执行相应手势，不成为独立的说话人来源。

当参考音频中的对话、旁白或歌词被直接重用，或当输入提示明确要求重新表演时，在 <d> 内保留确切的源词和原始语言。对不可理解的跨度写 [unclear]，而不是猜测或改述它们。将标点符号标准化为表达句子所需的基本书面标记，如 ,、.、? 和 !；删除重复的波浪号、表情符号、项目符号和重复或装饰性标点符号。在 </d> 之前分别用 .、? 或 ! 结束完整的陈述句、疑问句和感叹句。

当仅参考音色、节奏、情感或表达方式时，不要将参考音频中的原始对话带入目标视频。

根据目标视频中实际声音事件的顺序分配一次 (Sx)。在 detailed_description 中的每个实际声音事件处重用相应的 ID；在 subject_definitions 中绑定到目标说话人的 <Audio N> 定义也重用相同的 (Sx)，但从不独立分配新的。不要在 retention_analysis 中写 (Sx)。仅存在于直接重用的 BGM 或完整配乐中的口头提示使用 <Audio N>；由具体人物、角色、旁白者或其他独立声音来源实际产生的声音使用 (Sx)。

6. overall_soundscape 和 non_diegetic_music

这两个声音类别的定义遵循视频提示词编写指南（T2VA / I2VA / FL2VA / L2VA）。

overall_soundscape 总结整个视频的氛围和物理声音。对话、歌唱和与特定镜头同步的声音事件保留在 detailed_description 中：

overall_soundscape: 安静的室内房间音调和低通风嗡嗡声贯穿整个视频。

non_diegetic_music 描述角色听不到且仅观众可听到的背景音乐。当有音乐时，说明其乐器、速度和动态发展：

non_diegetic_music: 慢速的克制独奏钢琴配乐，下面有持续的低音大提琴，没有渐强。

当使用参考音频时，仅在匹配可听层的部分说明其复制或引用关系：氛围和音效属于 overall_soundscape，而仅观众的配乐属于 non_diegetic_music。如果同一音频提供两种内容，在每个部分描述相应的关系：

overall_soundscape: 从 <Audio 1> 复制的氛围层贯穿整个目标视频。
non_diegetic_music: <Audio 2> 被直接重用作完整的仅观众配乐。

仅在 detailed_description 的 <d> 内写完整的对话和歌词；不要在这两个部分中重复它们。

subject_definitions:
<Subject 1> 是 <Picture 1> 中的咖啡馆环境，有裸露的砖墙、带图案靠垫的橙色簇绒沙发、霓虹灯标志和木质咖啡桌。
<Subject 2> 是 <Picture 2>、<Picture 3> 和 <Picture 4> 中的蓬松白色萨摩耶，有厚白毛、尖耳朵、黑鼻子和卷尾巴。
<Subject 3> 是 <Video 1> 中的年轻金发女性，有长金发和卷起袖子的浅粉色纽扣衬衫。
<Subject 4> 是 <Video 2> 中的年轻男性，有短波浪棕发和带抽绳的深灰色连帽衫。
<Audio 1> 是 <Subject 3> (S1) 的声音音色参考，包含英语口语语音层。

summary:
[reference generation + audio reference] 目标视频显示 <Subject 3> 在 <Subject 1> 中吃饼干。<Subject 4> 带着 <Subject 2> 进入，狗向饼干扑去。三镜头交流使用 <Audio 1> 作为 <Subject 3> 的声音音色参考，并以罐头观众笑声结束。

retention_analysis:
<Subject 1> (appears in [Shot 1], [Shot 2], [Shot 3]): fully_preserved - 裸露的砖墙、橙色簇绒沙发、图案靠垫、霓虹灯标志和木质咖啡桌被保留。
<Subject 2> (appears in [Shot 1], [Shot 2]): fully_preserved - 萨摩耶的厚白毛、尖耳朵、黑鼻子和卷尾巴被保留。
<Subject 3> (appears in [Shot 1], [Shot 2], [Shot 3]): fully_preserved - 金发女性的身份、长头发和浅粉色衬衫被保留。
<Subject 4> (appears in [Shot 1], [Shot 2]): fully_preserved - 年轻男性的短波浪棕发和深灰色连帽衫被保留。
<Audio 1>: reference - 其声音音色指导 <Subject 3> 的对话表达，不复制原始信号。

detailed_description:
